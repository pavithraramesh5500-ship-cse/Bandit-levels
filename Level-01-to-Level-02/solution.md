**Level 01 → Level 02**

The goal of this level is to find the password for Level 02.

First, connect to the Bandit server as `bandit1`:

        ssh bandit1@bandit.labs.overthewire.org -p 2220

Enter the password obtained from Level 00 → Level 01.

List the files

        ls

The filename is - will appear , to read the file by using ./ tells Linux that - is a filename in the current directory

        cat ./-
